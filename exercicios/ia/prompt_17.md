# Prompt 17 — Criar plano de automação para time sem automação

Aja como um QA Architect contratado para estruturar automação do zero em uma empresa
com 5 QAs manuais, aplicação web + mobile, sem nenhum teste automatizado atual. Crie
um plano de 90 dias: Semana 1-2: diagnóstico e escolha de stack. Mês 1: MVP de
automação (smoke tests críticos). Mês 2: cobertura de regressão principal. Mês 3:
CI/CD integrado e mobile básico. Para cada fase: entregáveis, critérios de sucesso e
riscos.
