# Prompt 28 — Criar descrição de vagas para QA Sênior/Lead

Aja como um Head de Engineering escrevendo descrição de vaga atraente para um QA
Sênior especialista em automação. A vaga deve: descrever o impacto real do trabalho
(não lista de tarefas), stack e contexto técnico honesto, diferenciais da empresa
para o candidato, requisitos técnicos objetivos (separando must-have de
nice-to-have) e o que NÃO é a vaga (ser honesto filtra candidatos ruins). Stack:
[DESCREVA A STACK DO TIME]
®
 Boa vaga atrai candidato certo. Vaga genérica atrai 200 candidatos errados.
